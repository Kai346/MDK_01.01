# Введение С++

## Язык программирования C++

 > Язык программирование С++ - представляет высокоуровневый, компилируемый язык программирования общего назначения со статической типизацией. Своими корнями он уходит в язык C,который был разработан в 1969-1973 год компании
**Bell Lahs** **Деннисам Ритчи**

В начале 1980-х годов Датский программист **Бьерн Страуструп** работал в компании **Bell Laps** разработал C++ как расширение к языку С. Фактически в начале С++, просто дополнял язык С некоторыми возможностями ООП. Изначально язык назывался "Си с классами" \
\
С++ является компилируемым языком, а это значит, что компилятор транслирует(переводит) исходный код С++ в исполняемый файл, который содержит набор машинных инструкций.

## Зачем нужно компилировать исходный файл
Исходный C++ файл - это всего лишь код, но его невозможно запустить как программу и использовать как библиотеку, поэтому каждый исходный файл требует с компилировать в исполняемый файл.

## Этапы компиляции
1) Препроцессинг - это макропроцессор который преобразует программу для дальнейшего компилирования. На данной стадии происходит работа с препроцессорными деректирами
   - Например препроцессор добавляет headerы код ( # include, убивает комментарий)  
3) Компиляция - Преобразование в ассемблерный код, это промежуточный этап высокоуровневым языком и машинным кодом
4) Ассемблирование - перевод ассемблерного кода в машинный
   объектный файл - это созданный ассемблером промежуточный файл, хранящий кусок машинного кода, этот кусок машинного кода, который ещё не был связан вмести с другими кускам машинного кода, назывется объектом кода
5) Компоновка - (Компоновщик (линкер)) - связывает все объектные файл и статические библиотеки в единый исполняемый файл, который мы можем запустить

## Папки проекта

3. Ссылки (References) 
Указывает на внешние сборки (для C++/CLI или .NET).
В чистом C++ обычно пусто или содержит ссылки на Windows SDK.

4. Внешние зависимости (External Dependencies)
Автоматически собирает заголовки из подключенных библиотек (через #include).
Показывает, откуда берутся объявления функций/классов (например, iostream).
Редактировать нельзя — это отображение.

5. Исходные файлы (Source Files)
Файлы с расширением .cpp (реже .c).
Содержат реализацию функций, методов, логику программы.
Главный файл — обычно main.cpp с функцией main() (точка входа).

6. Файлы заголовков (Header Files)
Файлы с расширением .h или .hpp.
Содержат объявления классов, функций, констант, макросов.
Включаются в .cpp через #include.
Позволяют разделить интерфейс и реализацию.

7. Файлы ресурсов (Resource Files)
Необязательная папка.
Содержит .rc — скрипт ресурсов (иконки, меню, строки), а также сами ресурсы (.ico, .bmp).
В консольных проектах часто пуста.

8. Служебные файлы (не отображаются, но существуют)
.vs (скрытая папка) — кэш IntelliSense, параметры пользователя.
Debug/Release — папки с собранными объектными файлами (.obj) и итоговым .exe.
x64/x86 — подпапки для разных платформ.
